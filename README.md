# SteamPunk Bioacademy — Life & Steel

A portable, static companion website for the story. English is the default.
Spanish activates only after the visitor explicitly selects it.

## Open locally

Extract the ZIP and open `index.html`. All story records, illustrations, music
and animation scripts are included. An internet connection improves font loading.
The music starts only after an intentional click. Replay the ignition from Home.

## Publish with GitHub Pages

1. Create a repository in the account that will own the website.
2. Upload the extracted contents to its root, including `index.html` and `assets`.
3. In Settings → Pages, choose Deploy from a branch, then main and / (root).
4. GitHub displays the public address after the deployment completes.

Keep the assets folder structure intact. Relative paths support repository-based
GitHub Pages addresses. No build system, server, account database or API key is
required by the website. An OOC description banner can link to the resulting URL.

## Content

- 52 character records with the existing illustrated designs and assigned ranks.
- Six power disciplines, six regions and factions, and 31 field records.
- A living-engine ignition sequence, skip/replay controls and environmental FX.
- Two selectable licensed soundtracks, playback and volume controls.
- A mystery archive whose complete entity record requires an explicit reveal.
- Responsive layouts, keyboard controls and reduced-motion support.

Music attribution is in `CREDITS.txt` and the website's Soundtrack & Credits panel.
